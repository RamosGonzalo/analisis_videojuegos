# Análisis de Videojuegos con Python

Proyecto de análisis exploratorio de datos de videojuegos desarrollado con **Python**, utilizando **Jupyter Notebook**, **Pandas** y **Matplotlib**.

El proyecto forma parte de una sección del curso de Python dictado por **Federico Garay** en Udemy y tiene como objetivo aplicar conceptos de análisis y visualización de datos sobre un dataset de videojuegos.

## 🛠️ Tecnologías utilizadas

- **Python**
- **Jupyter Notebook / JupyterLab**
- **Pandas**
- **Matplotlib**
- **CSV**
